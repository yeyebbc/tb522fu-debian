## Interpretation and next step

Changing Debian to Ubuntu alone did not resolve the failure. The shared
kernel/display stack is the leading investigation target. Firmware and the
A830-enabled Mesa build also remained shared, so the comparison does not prove
that the kernel alone is responsible or identify a particular driver defect.

Android is running; selected Linux remains Debian CI78, with CI74/CI44 retained
as rollback choices. Ubuntu remains a separate test root; partition boundaries
and the installed selection are unchanged. The prior driver investigation
remains paused. The user subsequently replaced the EndeavourOS proposal with
the [Fedora 45 ARM64 comparison](../fedora45-trial.md), starting with image and
kernel compatibility before another boot. The original Ubuntu checkpoint tag
is retained unchanged; the follow-up commit records this change of plan.
