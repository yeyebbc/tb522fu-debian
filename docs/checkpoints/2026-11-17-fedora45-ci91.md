## Preparation corrections and limits

The original root extraction omitted the raw image's separate `/var` subvolume.
Its failed frozen archive and first startup-fault evidence are preserved. A
separate audited layer restores missing stock files/packaged directory metadata
without replacing runtime files. `systemd-repart.service` is explicitly masked;
both GPT copies and approved geometry/identities are verified. The first failed
boot is not reclassified as a pass.

The support-copy subset also missed three required Bluetooth peripheral files.
They were restored from this tablet's previously accepted private firmware
manifest; existing files must match. No firmware/calibration is published.
Bluetooth address setup now succeeds; pairing/radio-toggle checks remain open.
Fedora firewalld fails with this kernel's missing NF_TABLES support. SELinux
LSM, PSI and zram are also absent; the scoped trial compatibility controls are
documented in the [integration plan](../fedora45-trial.md). No Debian/Ubuntu
shared system libraries are imported into Fedora.

The first corrected connected test had no completed battery action because its
prompt was missed. It is retained as an incomplete action window, not a wake
failure. The user requested the successful capture above. Its failed physical
review triggers the owned clean return; native probe1 is preserved separately
from the successful independent recovery monitor0.

## Interpretation and next step

Fedora GNOME51/native newer Mesa reproduces the same battery-specific physical
failure as Ubuntu and Debian. This weakens a Debian-only desktop explanation.
The custom kernel, board integration and firmware remain shared, so this does
not prove a kernel-only cause or identify the faulty component. Connected wake
alone remains insufficient for promotion. Do not run an unchanged comparison.

Keep driver experimentation paused at this checkpoint. Any resumed investigation
should use these existing offline/connected logs to select a changed, falsifiable
kernel/firmware/display-lifecycle test before another boot. No new candidate or
hardware test is selected here. Production/default selection stays Debian CI78.
